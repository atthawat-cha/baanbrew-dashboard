การบ้าน
เพิ่มกราฟ “จำนวนบิลตามชั่วโมงของวัน” (ลองแยกตามสาขาด้วย) แล้วเขียนข้อสังเกตอย่างน้อย 3 ข้อจากกราฟ
ติดปัญหาบ่อย
-	กราฟว่างหรือยอดเป็น 0: ตัวเลขใน CSV ถูกอ่านเป็นข้อความ ให้สั่ง AI แปลง qty และ unit_price เป็น Number ก่อนคำนวณ
-	จำนวนบิลเยอะผิดปกติ (53,092): นับแถวแทนการนับ order_id ที่ไม่ซ้ำ
-	ยอดขายรายวันเลื่อนไป 1 วัน: ใช้ new Date(...).toISOString() ซึ่งแปลงเป็นเวลา UTC ให้ใช้ 10 ตัวอักษรแรกของ datetime แทน
-	npm install ไม่ผ่าน: ตรวจเวอร์ชัน Node.js และลองลบโฟลเดอร์ node_modules แล้วติดตั้งใหม่
